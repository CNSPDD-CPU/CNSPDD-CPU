# CNSIDD Website

Static bilingual website for the Center for Neuroscience and Innovative Drug Development at China Pharmaceutical University.

Live site: <https://cnspdd-cpu.github.io/CNSPDD-CPU/>

## Stack

- Jekyll
- GitHub Pages
- HTML/CSS
- Font Awesome

## Key Content Files

- `index.md`, `cn/index.md` - home pages
- `research.md`, `cn/research.md` - Research and Platforms pages
- `people.md`, `cn/people.md` - team templates
- `news.md`, `cn/news.md` - news templates
- `publications.md`, `cn/publications.md` - publication templates
- `contact.md`, `cn/contact.md` - contact pages
- `_layouts/default.html` - shared navigation and footer
- `_config.yml` - site configuration
